# Holidaze PE2

This is my Project Exam 2 submission for Noroff Front-End Development.

Holidaze PE2 is a booking website built with **React**, **Vite**, **JavaScript**, **Tailwind CSS**, and the **Noroff Holidaze API v2**. The application allows customers to browse venues, search for stays, create bookings, and manage their profile. Venue managers can create, edit, and delete venues, as well as view bookings for venues they manage.

## Features

- Register as customer or venue manager.
- Login and logout.
- Browse all venues.
- Search venues.
- View a single venue page.
- Create bookings.
- View customer bookings.
- Update profile and avatar.
- Create, edit, and delete venues as a venue manager.
- View bookings for managed venues.
- Responsive layout for desktop and mobile.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Nestorillo/holidaze.git
```

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Design

The design was created in Figma before and during development. I used a simple teal-based colour palette, rounded cards, large images, and clean forms to make the site feel modern and easy to use.

The layout was planned for both desktop and mobile screens. The goal was to make the booking flow clear, simple, and usable for both customers and venue managers.
